# Тропы

Приложение для пеших маршрутов по дикой природе России. Android.

Здесь публикуются установочные файлы приложения. Исходный код закрыт.

Сайт — [tropy.app](https://tropy.app)

> ⚠️ **Сейчас это бета-версия.** Приложение подано в RuStore и ждёт
> модерации; сборки здесь — предрелизные. Записанный поход может пропасть при
> обновлении: не берите эту версию как единственную запись важного похода.
> Подробнее — в разделе «Что нужно знать до установки».

## Что делает приложение

**Перед выходом.** Каталог троп: более 80 маршрутов, восемь регионов для
начала. У каждого маршрута линия взята из OpenStreetMap — нарисованных от руки
треков в каталоге нет. Видно длину, набор высоты, сложность и погоду в точке
старта.

**Чужой трек как маршрут.** Прислали файл GPX или KML — открывается прямо
из письма или мессенджера: ляжет на карту, покажет длину и подъёмы, и по нему
можно идти так же, как по маршруту из каталога.

**Карта на тропе, где нет связи.** Скачать можно маршрут из каталога, чужой
присланный трек или любой район — выбрав его рамкой прямо на карте. Карта
сохраняется в телефон целиком, вместе с рельефом: маршрут в 50 км занимает
около 23 МБ. А если карты этого места нет, а связь ещё ловит, приложение
предложит скачать квадрат вокруг тебя у начала похода — спросив перед этим,
потому что пойдёт мобильный трафик.

**Запись похода.** Трек, расстояние, набор высоты, темп и скорость. Работает
с погашенным экраном. Записанный поход остаётся у тебя: им можно поделиться
ссылкой с конкретным человеком или не делиться вовсе, а можно выгрузить
файлом GPX — бесплатно и всегда.

**Состояние тропы.** Брод, завал, снег, клещи, родник, стоянка, вид — отметки
от тех, кто здесь прошёл. О том, что впереди по маршруту, приложение
предупреждает заранее, за несколько сотен метров, и делает это без связи.

## Установка

Свежий файл — на вкладке [Releases](https://github.com/gutugo/tropy/releases),
самый верхний. Тот же файл лежит на [tropy.app](https://tropy.app).

Нужен **Android 7.0** или новее. При установке Android спросит разрешение
ставить приложения не из магазина — это его обычный вопрос к любому такому
файлу.

Обновления пока не приходят сами: пока приложения нет в RuStore, новую сборку
нужно ставить так же, файлом, поверх старой. Записанное при этом остаётся
на месте — все сборки подписаны одним ключом.

## Что нужно знать до установки

Это стадия тестирования, и приложение собирает больше обычного — иначе
поломку, случившуюся в лесу без связи, не найти: переспросить будет некого.

- **Сырые показания GPS содержат ваш маршрут** — подробнее, чем сохранённый
  поход. **Собираются только с вашего согласия**: при первом запуске приложение
  спрашивает прямо, присылать ли эту запись, и ответ можно передумать
  в «Настройки» → «Сохранять сырые данные». Отказ ничего не ограничивает.
  Если согласились — уходят только по Wi-Fi и хранятся 30 дней; всё, что
  хранится, видно списком: «Настройки» → «Запись GPS».
- **Журнал работы приложения** — какие экраны открывались и что сломалось.
  Координат и маршрутов не содержит.
- **Отчёт о падении** уходит сам, когда приложение падает.

Про возможную потерю похода написано в приложении — «Настройки» →
«О приложении», под номером версии. Подробности — в [политике конфиденциальности](https://tropy.app/privacy/),
раздел о стадиях тестирования.

**Что-то сломалось — напишите:** «Настройки» → «Сообщить о проблеме». Версия,
модель телефона и состояние приложения приложатся сами.

## English

**Тропы** (Tropy) is a hiking app for Russia's wild nature: a trail catalog
with geometry taken from OpenStreetMap, offline maps for places with no signal,
GPS track recording, imported GPX/KML tracks you can follow, and
trail-condition reports left by people who walked there. Android, in Russian.

This repository publishes the installable builds. The source code is private.

⚠️ Current builds are **pre-release beta builds**: recorded hikes may be lost
on update, and the app can collect raw GPS traces for debugging — only if you
agree on first launch; declining changes nothing else. See the Russian
section above and the [privacy policy](https://tropy.app/privacy/).
